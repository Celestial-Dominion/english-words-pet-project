=== if-nuance
sum: Những cụm có if nhưng không phải câu điều kiện thông thường. If anything, … = nếu có khác thì là ngược lại (Prices haven't fallen. If anything, they've gone up). rarely, if ever / few, if any / little, if any / if at all = hiếm, ít — nếu có thì cũng rất ít. X, if not Y = X, thậm chí là Y (difficult, if not impossible · hundreds, if not thousands). only if = chỉ khi, điều kiện duy nhất (đưa lên đầu câu thì đảo ngữ: Only if you study will you pass) ≠ even if = kể cả khi. whether or not = dù có hay không (không nói or no).
form: If anything, … (nếu có khác thì là ngược lại) | If anything, we're busier than last year.
form: rarely, if ever · few / little, if any · if at all | Rarely, if ever, do customers complain.
form: X, if not Y (thậm chí là Y) | Hundreds, if not thousands, of people came.
form: only if (chỉ khi) · whether or not (dù có hay không) | We'll play whether or not it rains.
cast: nam jay
bg: cafe
words: complain, cost, menu, difference, weight, customer

#hook
nam: Business looks slow today. Are you worried? | Hôm nay quán có vẻ vắng. Anh có lo không? [thinking]
jay: Not really. If anything, we're busier than last year. | Không hẳn. Có khác thì là quán còn đông hơn năm ngoái. [explain]
nam: Do customers ever complain about the prices? | Khách có bao giờ phàn nàn về giá không? [thinking]
jay: Rarely, if ever. Hundreds, if not thousands, of people come here every month. | Hiếm lắm, nếu có. Hàng trăm, thậm chí hàng nghìn người đến đây mỗi tháng. [happy]
> Ba cụm với [[if]] không phải câu điều kiện thông thường. [[If anything]]: nếu có gì khác thì là ngược lại. [[Rarely, if ever]]: hiếm khi, nếu có thì cũng rất ít. [[Hundreds, if not thousands]]: hàng trăm, thậm chí có khi hàng nghìn.

#form
th: Cách nói | Nghĩa
tb: If anything, … | nếu có khác thì là ngược lại
tb: rarely, if ever · few, if any | hiếm, ít, nếu có thì rất ít
tb: X, if not Y | X, thậm chí là Y
tb: only if + mệnh đề | chỉ khi
tb: whether or not + mệnh đề | dù có hay không
> Các cụm này giúp nói chính xác mức độ. Người nói vừa đưa ra nhận định, vừa cho thấy mình cân nhắc cẩn thận tới đâu.
f: X + [, if not] + Y (mạnh hơn X)
> [[If not]] đứng giữa hai từ nghĩa là “thậm chí là”: [[difficult, if not impossible]], khó, thậm chí là không thể.

#examples
- The new model isn't cheaper. {If anything|k}, it's more expensive. | Mẫu mới không rẻ hơn. Có khác thì là đắt hơn.
- There's little, {if any|k}, difference between them. | Giữa chúng có rất ít, nếu có, sự khác biệt.
- The task is difficult, {if not|k} impossible. | Việc này khó, thậm chí là không thể.
- We'll play {whether or not|k} it rains. | Dù trời có mưa hay không, chúng tôi vẫn chơi.

#contrast
vs: I'll go only if you come with me. | Tôi chỉ đi nếu bạn đi cùng. || only if: điều kiện duy nhất
vs: I'll go even if you don't come. | Tôi vẫn đi kể cả khi bạn không đi. || even if: đằng nào cũng đi
> [[Only if]] đặt ra một điều kiện duy nhất: không có nó thì không đi. [[Even if]] thì ngược lại: điều kiện đó chẳng thay đổi được gì.

#natural
rank: best | He hardly ever calls me. | Anh ấy hầu như chẳng bao giờ gọi cho tôi.
rank: ok | He rarely, if ever, calls me. | Anh ấy hiếm khi, nếu có, gọi cho tôi.
> Khi nói chuyện, [[hardly ever]] đơn giản và tự nhiên hơn. [[Rarely, if ever]] mang giọng văn viết, dùng khi muốn nhấn mạnh và chính xác.

#mistakes
x: If something, prices have gone up. => If anything, prices have gone up. | Có khác thì là giá còn tăng lên. >> Cụm cố định: [[If anything]].
x: We'll go whether it rains or no. => We'll go whether it rains or not. | Dù trời có mưa hay không, chúng tôi vẫn đi. >> Dùng [[or not]], không dùng [[or no]].
x: Only if you study you will pass. => You will pass only if you study. | Bạn chỉ đỗ nếu bạn chịu học. >> Đặt [[only if]] giữa câu. Đưa lên đầu câu thì phải đảo ngữ: [[Only if you study will you pass]].

#dialogue
nam: So will you raise your prices? | Vậy anh có tăng giá không? [thinking]
jay: Only if my costs keep rising. | Chỉ khi chi phí tiếp tục tăng thôi. [explain]
nam: And the new menu? | Còn thực đơn mới thì sao? [thinking]
jay: That's happening whether or not prices change. Customers love new things! | Cái đó thì giá có đổi hay không cũng làm. Khách thích cái mới mà! [happy]

#recall
? Nói bằng tiếng Anh, dùng [[if anything]]: Anh ấy không gầy đi. Có khác thì là béo lên. => He hasn't lost weight. If anything, he's put on weight. | Anh ấy không gầy đi. Có khác thì là béo lên.
? Nói bằng tiếng Anh, dùng [[whether or not]]: Dù bạn có thích hay không, bạn cũng phải làm. => Whether or not you like it, you have to do it. | Dù bạn có thích hay không, bạn cũng phải làm.

#recap
> [[If anything]]: có khác thì là ngược lại. [[Rarely, if ever]], [[few, if any]]: hiếm, ít, nếu có. [[X, if not Y]]: thậm chí là Y. [[Only if]]: chỉ khi, khác [[even if]]. [[Whether or not]]: dù có hay không. Những cụm nhỏ giúp nói đúng mức độ.

#practice
fill: The city isn't quieter now. ___, it's noisier. | If anything* / If not / Only if || If anything = có khác thì là ngược lại.
fill: He rarely, if ___, eats meat. | ever* / any / not || rarely, if ever.
fill: It will take weeks, if ___ months. | not* / ever / any || X, if not Y = thậm chí là Y.
fill: You can borrow my car ___ you drive carefully. | only if* / even if / if anything || only if = chỉ khi.
fix: We'll go whether it rains or no. | We'll go whether or not it rains.* / We'll go whether it rains or no rain. / We'll go whether it not rains. || whether or not.
transform: Viết lại với only if: | You can come, but you must be quiet. >> You can come only if you are quiet.* / You can come only you are quiet. / Only if you can come are quiet. || only if + mệnh đề.
choice: “There's little, if any, sugar in it.” nghĩa là: | Có rất ít đường, có khi không có tí nào* / Có nhiều đường / Có đường nếu bạn muốn || little, if any = rất ít, có khi không có.
type: Few, if ___, students failed the test. | any || few, if any.
order: The / task / is / difficult, / if / not / impossible. | Việc này khó, thậm chí là không thể.
listen: Not really. If anything, we're busier than last year. | Not really. If anything, we're busier than last year.* / Not really. If anything, we're quieter than last year. / Not really. Anyway, we're busier than last year. || Nghe if anything … busier.
